Windows warns about new apps it doesn't know yet. This is expected. To continue:

1. **In Edge's download list:** point at the file, click **…**, then **Keep**.
2. **In the box that opens:** click the **arrow beside Delete**, then **Keep anyway**.
3. **On the blue "Windows protected your PC" screen:** click **More info**, then **Run anyway**.

## For IT teams

- Silent install for all users (as SYSTEM or admin): `"FoodOptimizer-0.9.0-Windows.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /CLOSEAPPLICATIONS /ALLUSERS`
- Exit 1: the app is open; retry. Exit 9: security software blocked a file.
- Runs only on this PC and sends nothing. FoodOptimizer.exe and its Python connect only to 127.0.0.1.
- Needs 64-bit Windows 10 (22H2) or Windows 11 and 2 GB free.
- Unsigned: allow-list it by file hash, not by publisher.
