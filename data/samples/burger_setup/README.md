# Example setup - plant-based burger (illustrative, no results)

How to set up a project: calculated rows (hydration water as 2.2 × the textured proteins, remaining water as "= rest"), pre-mixes, a process setting, records and a formulation total. Every value, target and method step is illustrative: not measured, not from a panel and not from any study; the project has no results.

Rebuild the shipped project from `burger_ingredients.csv`: `python data/samples/burger_setup/build.py` (writes the `.json` here). `tests/test_sample_burger.py` checks it matches.
